# Czarna lista - słowa, frazy, kalki do wycięcia

Czytaj przed każdym pisaniem. Przy korekcie najpierw wypisz znaleziska
z numerami akapitów, nic nie poprawiając - korekta dopiero w drugiej fazie.

## Bezwzględny zakaz

- **"społeczność"** → gracze, fani, użytkownicy, czytelnicy (konkretna grupa)

## Zużyte frazesy

"nie pozostawia złudzeń", "jedno jest pewne", "z pewnością", "czas pokaże",
"budzi emocje", "to coś więcej niż", "nie zwalnia tempa", "wbrew wszelkiej
logice", "wywołać burzę", "to nie X – to Y" (z kreską), "rezonuje z",
"wpisuje się w", "ikoniczny", "dedykowany", "ekosystem" (metaforycznie)

## Antyinflacja dramatyzmu

| Zamiast | Daj |
|---|---|
| "rewolucja" / "rewolucyjny" | konkret, co się zmienia |
| "przełomowy" | konkret |
| "szokujące" | "zaskakujące" |
| "zdobyć serca odbiorców" | liczby, wyniki |
| "zmienia zasady gry" | opisz, co konkretnie |
| "wyznacza nowy standard" | dowód albo wytnij |
| "zyskać uznanie" / "zyskać popularność" | nazwij konkret: "zdobyła popularność", "zebrała świetne recenzje", "zasłynęła z X" |

## Kalki składniowe

| Zamiast | Daj |
|---|---|
| "eksplorować" (temat) | "zgłębiać" |
| "stanowić" (nadużywane) | właściwy czasownik |
| "podczas gdy" (nadużywane) | "natomiast", "z kolei" |
| "w kontekście..." | "jeśli chodzi o..." lub pomiń |
| "w zakresie" | "pod względem" lub pomiń |
| "w ramach" | "w" lub pomiń |
| "można stwierdzić, że" | wprost |
| "można zauważyć" | "widać" lub wprost |
| "należy podkreślić" | bez zapowiedzi, wprost |
| "naprawdę" | pomiń lub konkret |
| "innowacyjny" | "nowatorski" lub opisz |
| "kompleksowy" | "rozbudowany" |
| "głębia" (samodzielne) | "złożoność" |
| "zanurzyć się" | "zagłębić się" |
| "to nie tylko..., ale też..." | dwa osobne zdania |
| "sugerować" (nadużywane) | "wskazują na", "świadczą o" |
| "przyciągnąć uwagę" | "zwrócić uwagę" |

## Puste wzmacniacze

"absolutny", "rewolucyjny", "niesamowity", "fantastyczny", "ogromny",
"astronomiczny" - tnij albo zastąp liczbą/konkretem.

## Zakazane otwarcia akapitów

"Warto zauważyć/podkreślić/wspomnieć, że...", "Nie sposób nie...",
"Co ciekawe...", "Nie da się ukryć...", "Należy pamiętać...",
"Trzeba przyznać, że..."

Test: usuń otwarcie - jeśli zdanie po nim ma sens, wytnij otwarcie.

## Hedgingi i zapychacze

Frazy, które rozmywają twierdzenie lub zapowiadają treść zamiast ją dostarczyć.
Wytnij całą frazę - zdanie po niej broni się samo.

| Fraza | Problem | Zamiennik |
|---|---|---|
| "Warto również wspomnieć, że..." | rampa przed treścią | wytnij, zacznij od treści |
| "Nie można zapominać, że..." | hedge + rampa | "Jest jeszcze X:" albo wytnij |
| "Jednocześnie warto podkreślić, że..." | podwójny hedge | "Jednocześnie" albo wytnij całość |
| "Na podstawie podanych informacji" | tic konwersacyjny w tekście | "Z danych wynika" albo wytnij |
| "Ważne jest, aby pamiętać, że..." | patronizujące + rampa | "Pamiętaj:" albo wytnij |
| "Kolejnym ważnym aspektem jest..." | sygnał roli akapitu | zacznij od konkretu |
| "Należy w tym miejscu zaznaczyć, że..." | akademicka rampa | wytnij, wprost |
| "Nie bez znaczenia pozostaje fakt, że..." | podwójne zaprzeczenie + rampa | wytnij, wprost |
| "Warto w tym kontekście podkreślić..." | rampa + hedge | wytnij, wprost |

## Pompowanie ważności

Konstrukcje łączące konkretny fakt z "szerszym kontekstem" bez dowodu.
Wytnij albo uzupełnij konkretnym dowodem - znaczenie musi wynikać z faktów.

- "...co stanowi ważny krok w kierunku..."
- "...wyznaczając nowy standard w branży..."
- "...wpisuje się w szerszy trend..."
- "...ma kluczowe znaczenie dla przyszłości..."
- "...stanowi przełom w dziedzinie..."
- "...co może mieć daleko idące konsekwencje..."
- "...otwiera nowe możliwości dla..."
- "...toruje drogę do..."

Część z tych fraz pokrywa się z "antyinflacją dramatyzmu" - tu chodzi
o wzorzec łączenia faktu z "szerszym kontekstem", nie o sam wzmacniacz.

## Akapity ramowe

AI zaczyna akapity sygnałem roli zamiast wejściem w treść. Wytnij rampę,
zacznij od konkretu - pierwszego zdania, które niesie informację.

- "Kolejnym ważnym aspektem jest..."
- "Kluczową kwestią pozostaje..."
- "Nie bez znaczenia jest fakt, że..."
- "Innym istotnym elementem jest..."
- "Na uwagę zasługuje również..."
- "Warto w tym miejscu zwrócić uwagę na..."

## Zakazane łączniki (max 2 w całym tekście, nigdy dwa pod rząd)

"Ponadto", "Co więcej", "Dodatkowo", "Jednocześnie", "W rezultacie",
"W konsekwencji", "Tym samym", "Mając to na uwadze"

## Retoryczne rampy (wytnij rampę, zostaw pointę)

"A gdyby tak...", "Pomyśl o tym:", "Chodzi o to, że:", "I tu pojawia się
pytanie:", "I to jest w porządku."

Zapowiadanie pointy zamiast jej dostarczenia. Pointa po rampie broni się sama.

## Konstrukcje przeciwstawne (rodzina - jedno miejsce)

Wszystkie budują tezę przez odepchnięcie się od zaprzeczonej połowy. Mechanizm:
definiowanie przez negację, lustrzana symetria udaje myśl. Kontrast bywa mocny,
więc to racjonowanie, nie zakaz absolutny - ale poniższe kształty tnij agresywnie,
bo wchodzą automatycznie i robią z tekstu manifest.

Kształty do wycięcia:

| Kształt | Przykład | Reżim |
|---|---|---|
| Ogon przecinkowy "X, nie Y" | "Konkretny poradnik, nie ogólniki." | zakaz |
| Ogon "X, a nie Y" | "Pisz wprost, a nie zawile." | zakaz |
| "Nie chodzi o X. Chodzi o Y." | "Nie chodzi o cenę. Chodzi o zaufanie." | zakaz |
| Stopniująca "Mniej X, więcej Y" | "Mniej obietnic, więcej dowodów." | zakaz |
| Paralela "Tam, gdzie X, (tam) Y" | "Tam, gdzie inni dodają, ja tnę." | zakaz |
| "to nie X – to Y" (z kreską) | - | zakaz (też w "zużytych frazesach") |
| Antyteza "Nie A. To B." / "X nie ma A, X ma B" | "Komputer nie ma wątpliwości. Komputer ma instrukcje." | max raz na tekst, nigdy w pozycji ciosu |
| Negatywne wyliczanie "Nie X. Nie Y. Z." | - | max raz na tekst |

**Test (per zdanie):** usuń zaprzeczoną połowę. Jeśli twierdząca część niesie
pełny sens - negacja była ozdobą, tnij. Zostaw tylko, gdy zaprzeczenie prostuje
konkretne, realne oczekiwanie czytelnika ("To nie jest darmowe - kosztuje X").

Przepisy na przepisanie (afirmacja + przyczyna, stopniowanie, zwykłe zdanie) →
`zasady-jezykowe.md`, sekcja "Konstrukcje przeciwstawne".

## Meta-komentarze (wytnij, zastąp konkretem)

"świetny przykład", "pokazuje, że", "to dowód", "cała sytuacja". Zdania
z podmiotem "rynek" / "branża" / "segment" zamiast konkretnych firm lub danych.

Zdania-zapowiedzi (następne zdanie powie to lepiej): "To nie pierwszy taki
przypadek.", "Warto w tym miejscu zauważyć, że..."

## Cudze metafory

Sprawdź, czy porównania i celne opisy nie są adaptacją ze źródła. Sparafrazowana
metafora ze źródła to wciąż plagiat stylistyczny.
